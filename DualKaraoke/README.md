# デュアルカラオケ（Androidアプリ）

1台のAndroidスマホから、**2つの音源を別々の出力機器へ同時に**流すアプリです。

| 出力 | 音源 | 聞く人 |
|---|---|---|
| 🎧 Bluetoothイヤホン | ボーカル入り（ガイド） | 歌う人だけ |
| 🔊 USB／有線／本体スピーカー | カラオケ（伴奏のみ） | 会場のみんな |

## 重要な制約

Androidは通常、**Bluetoothで音楽（A2DP）を流せるのは同時に1台まで**です。
公開APIで2台のBluetooth機器に別々の音を送ることはできません。おすすめの構成は次のとおりです。

- イヤホン：Bluetooth
- スピーカー：USB-C接続のスピーカー、USB-C→3.5mm変換アダプタ＋有線スピーカー、または本体スピーカー

## 使い方

1. 「歌手用」でボーカル入り音源を、「スピーカー用」でカラオケ音源を選ぶ
2. それぞれの「出力先」を選ぶ（初回は自動でBluetooth／USBを選びます）
3. ▶ 再生
4. **ずれ補正**：Bluetoothイヤホンは0.1〜0.3秒ほど遅れて聞こえます。
   イヤホンとスピーカーを同時に聞きながら、スライダーで「スピーカーを◯ms遅らせる」を調整してください。
   値は保存されます。

### 曲ボタン（1〜12）

よく歌う曲を事前に登録しておけます。

- **登録**：歌手用・スピーカー用の音源を選んだあと、番号ボタンを**長押し** →「今選んでいる曲を登録」
- **呼び出し**：番号ボタンを**タップ**すると、2つの音源がまとめて切り替わります（選択中のボタンはオレンジ色）
- 長押しメニューから「名前を変更」「登録を消す」もできます

ずれ補正は再生中に動かしても、音を止めずに反映されます。

## ビルド

- Android Studioで `DualKaraoke/` フォルダを開いて実行
- またはGitHubにpushすると、GitHub Actions（`.github/workflows/android.yml`）が
  デバッグAPKをビルドします。Actionsの実行結果の「Artifacts」から `DualKaraoke-debug-apk` をダウンロードして
  スマホにインストールできます（提供元不明のアプリのインストールを許可する必要があります）。

対応：Android 8.0（API 26）以上

## 仕組み

各音源を `MediaCodec` でデコードし、出力機器ごとの `AudioTrack` に流しています（`app/src/main/java/io/github/sakurazakiharuo/dualkaraoke/DualPlayer.kt`）。
出力先は `AudioTrack.setPreferredDevice(AudioDeviceInfo)` で指定します。
両方の出力に約0.4秒分の音を貯めてから同時に再生を始め、再生中は位置を飛ばしません。
ずれ補正は、無音の挿入または音の読み飛ばしで反映します。

## Google Play へのリリース手順

### 1. 署名付きアプリバンドル（.aab）を作る
1. Android Studio で **Build → Generate Signed App Bundle or APK** → **Android App Bundle** を選ぶ
2. 初回は **Create new...** でアップロード鍵を作る
   - 保存場所はこのフォルダの**外**（例：`Documents/keys/dualkaraoke-upload.jks`）
   - パスワードと Key alias（例：`upload`）を控えておく
   - ⚠️ この鍵ファイルとパスワードは絶対になくさない・公開しない（Gitにも入れない）
3. Build Variant は **release** を選んで Create
4. `DualKaraoke/app/release/app-release.aab` ができる

更新版を出すときは、`app/build.gradle.kts` の `versionCode` を1つ増やし（`versionName` も変更）、同じ鍵で作る。

### 2. Play Console に登録する素材
| 項目 | 用意したもの |
|---|---|
| アプリアイコン 512×512 | `store/icon-512.png` |
| フィーチャーグラフィック 1024×500 | `store/feature-1024x500.png` |
| スクリーンショット（2枚以上） | スマホで撮影する（市販曲の曲名やジャケットが写らないように） |
| プライバシーポリシーURL | `https://nakamurakozo.tv/privacy.html`（`dualkaraoke/privacy.html` をアップロードしたもの） |

### 3. データセーフティの回答
アクセス解析（Firebase Analytics）を使っているため、次のように回答する。
- データを収集しますか → **はい**
- データを共有しますか → **いいえ**（Google はサービス提供者として処理するため「共有」に当たらない）
- データは転送時に暗号化されますか → **はい**
- ユーザーがデータの削除をリクエストできますか → **いいえ**（アプリをアンインストールすればアプリ内の設定は消える）
- 収集するデータの種類
  - **アプリのアクティビティ → アプリの操作**：収集する／必須ではない（アプリ内でオフにできる）／目的：**分析**
  - **デバイスまたはその他の ID**：収集する／必須ではない／目的：**分析**
- 広告ID → **使用しない**（マニフェストで権限を外している）
