# 初期推し（YouTube歌動画低再生数リスト）

登録者 0〜300 人のチャンネルが直近 3 日以内に投稿した日本語の歌動画を集め、
再生数の昇順（少ない順）に並べた HTML を毎朝 7 時に生成する。

## 構成

```
cron（毎朝7時）→ fetch.php（PHP CLI）→ YouTube Data API v3 → 静的 index.html を書き出し
```

- 閲覧時に API を呼ばない（静的 HTML）。表示が速く、API 割り当ても消費しない
- PHP はさくらのレンタルサーバに標準で入っているため、追加インストール不要

## 処理の流れと API 消費量（無料枠 10,000 ユニット/日）

| 手順 | API | 消費 |
|---|---|---|
| 5 キーワード × 最大 4 ページ（50 件/ページ）を検索。条件: 動画・音楽カテゴリ・3 日以内・新しい順・地域 JP・言語 ja | search.list | 100 × 20 = 2,000 |
| 候補動画の再生数・言語・再生時間を取得 | videos.list | 50 件ごとに 1（〜20） |
| チャンネルの登録者数を取得 | channels.list | 50 件ごとに 1（〜20） |

合計 約 2,050 ユニット/日。`pages_per_keyword` を増やせば取りこぼしは減る（上限目安 9 ページ程度）。

絞り込み（fetch.php 内）:
- 登録者数 0〜300（登録者数を非公開にしているチャンネルは除外）
- 日本語: 音声言語が `ja`、またはタイトル/説明文にひらがな・カタカナ・漢字を含む
- 「MV」「music video」の検索でしかヒットしなかった動画は、説明欄にひらがなが含まれるものだけ残す（オリジナル曲系のキーワードでもヒットしていれば不要）
- タイトル・タグに「歌ってみた」「カバー」「cover」「BGM」などを含む動画は除外（英単語は単語単位で判定するため "discover" などには反応しない。除外語は `config.php` の `exclude_words` で変更可）
- 8分以上の動画は除外（`max_duration_sec`）
- ライブ配信中・プレミア公開待ちは除外

## さくらのレンタルサーバへの設置

1. Google Cloud Console でプロジェクトを作成し「YouTube Data API v3」を有効化、API キーを発行
2. このフォルダを公開ディレクトリ外にアップロード（例: `/home/アカウント名/youtube-indie-songs/`）
3. `config.sample.php` を `config.php` にコピーして API キーを設定（出力先は自動で `~/www/indie-songs/index.html`）
4. SSH で動作確認: `/usr/local/bin/php /home/アカウント名/youtube-indie-songs/fetch.php`
5. コントロールパネル →「スクリプト設定」→「CRON設定」で登録
   - 実行コマンド: `/usr/local/bin/php /home/アカウント名/youtube-indie-songs/fetch.php`
   - 分 `0` / 時 `7` / 日・月・曜日 `*`（さくらの cron は日本時間）
6. `https://アカウント名.sakura.ne.jp/indie-songs/` で表示を確認

## 動作確認・トラブル時

- 実行のたびに `~/youtube-indie-songs/fetch.log` に結果が追記される
  - `OK candidates=… listed=…` … 正常に更新
  - `WARN search stopped …` … 検索の途中で割り当て超過など。集められた分だけで更新
  - `ERROR …` … 更新できず、ページは前回のまま
- ログに何も追記されていない日は、cron 自体が動いていない（CRON 設定のコマンド・時刻を確認）
- search.list は**1日100回まで**（1回の更新で20回使用）。リセットは日本時間16時。手動テストを繰り返すと翌朝7時の更新で上限に達することがある

## 注意点・限界

- **検索の網羅性**: search.list は 1 クエリ最大 500 件程度までしか返さず、「MV」「music video」のような広い語は 3 日分でも件数が多い。小規模チャンネルを拾うため新しい順（order=date）で取得している。取りこぼしを減らすならページ数を増やす
- **登録者数の精度**: API の登録者数は 3 桁に丸められるが、300 人以下の範囲では実質正確
- **日本語判定**: 投稿者が言語を設定していないことが多いため文字種で判定。中国語の漢字のみのタイトルが混ざる可能性がある（気になる場合はかな必須に変更）
- **歌動画の判定**: 音楽カテゴリ＋キーワード＋除外語で絞っている。除外語をタイトル・タグに書いていない歌ってみた・カバー動画は残る可能性がある
- **規約**: YouTube API 利用規約に従い、データは毎日上書きで最新化し、ページに YouTube データ由来である旨を表示している
