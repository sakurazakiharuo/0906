# 初期推し（YouTube歌動画低再生数リスト）

登録者 0〜300 人のチャンネルが直近 3 日以内に投稿した日本語の歌動画を集め、
再生数の昇順（少ない順）に並べた HTML を毎朝 7 時に生成する。

## 構成

```
cron（毎朝7時）→ fetch.php（PHP CLI）→ YouTube Data API v3 → 静的 index.html を書き出し
```

- 閲覧時に API を呼ばない（静的 HTML）。表示が速く、API 割り当ても消費しない
- PHP はさくらのレンタルサーバに標準で入っているため、追加インストール不要

## 3 言語（日本語・繁體中文・한국어）

同じ仕組みを言語ごとに動かし、言語ごとのページを作る（ページ上部のタブで切り替え）。設定は `languages.php`。

| | 日本語 | 繁體中文 | 한국어 |
|---|---|---|---|
| ページ | index.html | zh-tw.html | ko.html |
| 検索語 | オリジナル曲・オリジナルソング・オリジナル楽曲・MV・music video | 原創歌曲・原創曲・自創曲・創作歌曲・MV | 자작곡・창작곡・오리지널곡・MV・뮤직비디오 |
| 検索の地域・言語 | JP / ja | TW / zh-Hant | KR / ko |
| 言語の判定 | 音声が日本語、または**かな**がある | 音声が繁体中文、または**繁体字が簡体字より多い**（かな・ハングルの文章は除く） | 音声が韓国語、または**ハングル**がある |
| 除外語（タイトル・タグ） | 歌ってみた・カバー・cover・BGM | 翻唱・cover・動態歌詞・抖音・無損・KTV・卡拉OK・伴奏・歌單・playlist・BGM・一小時・循環播放 など | 커버・cover・불러보았다・노래방・MR・반주・플레이리스트・플리・BGM・1시간・반복재생・가사/해석 など |
| まとめ系（タイトル） | ランキング・TOP10・まとめ・再生回数 など | 排行・排名・TOP10・合集・串燒・盤點・反應 など | 랭킹・순위・TOP10・모음・메들리・리액션 など |
| 検索ページ数 | 4（20 回） | 3（15 回） | 3（15 回） |

- 検索回数は 1 回の更新で合計 50 回（1 日の上限 100 回）。上限に達しても特定の言語だけ 0 件にならないよう、言語を順番に回して検索する（日本語 1 語目 → 中文 1 語目 → 한국어 1 語目 → 日本語 2 語目 …）
- 候補が 0 件の言語でページがまだなければ空のページを作る（前回のページがあれば残す）
- 検索の上限は API キー（Google Cloud のプロジェクト）ごと。同じキーでテストするとサーバの cron の分が減る
- AI の判定は全言語共通（人工智慧・人工智能・인공지능 なども対象）。タイトル・説明欄・タグ・チャンネル名のどこかで AI・Suno などに触れた動画が 1 本でもあるチャンネルは、すべての動画を除外し `ai_channels.json` に記録して次回以降も除外する（`ai_allow_channels` に書いたチャンネルは対象外）
- 量産型の除外: 3 日間にフル尺（90 秒以上）の曲を 5 本以上出しているチャンネルは除外（`max_full_songs_per_window`、既定 4 本まで）
- ファンチャンネル（チャンネル名に ファン・粉絲・왕팬・팬・fan など）は除外
- タイトルに vs（比べる動画）がある動画、韓国語は 정규N집・타이틀곡（プロのアルバム曲の紹介）も除外
- 記録済みチャンネルは言語ごと: channels.json / channels-zh.json / channels-ko.json
- 除外ボタンの除外リストは全言語共通
- config.php の `'languages' => ['zh' => [...], 'ko' => [...]]` で言語ごとの設定を上書きできる（例: `'watch_channels'`）。`'enabled_languages' => ['ja']` で日本語だけに戻せる

## 候補動画の集め方

1. **キーワード検索**（search.list）… 「オリジナル曲」「オリジナルソング」「オリジナル楽曲」はカテゴリを問わず、「MV」「music video」は音楽カテゴリだけ検索
2. **記録済みチャンネルの新着確認**（playlistItems.list）… 一度リストに載ったチャンネルは `channels.json` に自動記録され、次回から検索に頼らず新着動画を直接確認する。検索の「1日100回」は使わない（1チャンネル1ユニット）
   - `config.php` の `watch_channels` に書いたチャンネルは常に確認する
   - 登録者が上限（300人）を超えたチャンネルは記録から自動で外れる
   - 記録済みチャンネル経由の動画は、タイトル・タグ・説明欄に検索キーワードがあるものだけ載せる（雑談動画などを除く）

DB は使わず、記録は `~/youtube-indie-songs/channels.json`（テキストファイル）に保存する。

## ピックアップ

リストの上に「ピックアップ」欄を表示する。動画は視聴できないため、API で取れる手がかりで判定する。

- 登録者 10 人以下（`pickup_max_subscribers`）
- 量産型ではない: **歌動画だけを数えて**、直近 30 日が 12 本以下、かつ平均ペースが週 3 本以下（雑談・ゲームなど歌以外の投稿は数えない。歌動画かどうかは最新 50 本のタイトル・説明欄の語 `song_words` で判定）
- AI に触れていない: タイトル・説明欄・タグ・チャンネル名に AI / suno / udio / mureka などの語がない（公開リストのタグ判定より厳しい）
- 作りこみ点数が 3 点以上（`pickup_min_score`）
  - 説明欄のクレジット（作詞・作曲・編曲・歌・映像・イラスト・ミックス・演奏）2 種以上 +1、4 種以上 +2
  - 説明欄に歌詞 +1 / 2 分以上のフル尺 +1 / タイトルに MV・Lyric Video など +1 / 説明文 300 文字以上 +1
  - 1 分未満・#shorts は -2
- 1 チャンネル 1 本、点数の高い順に最大 10 件。選んだ理由をタグで表示
- X 投稿用の別ページ（`output_post_html`）に、ピックアップごとの投稿文と「𝕏 でポスト」ボタンを出す。押すと投稿文入りの X 投稿画面が開く（X API は使わないので無料）
  - 投稿文はページ上で編集でき、文字数（280 字換算）も表示
  - 40 秒以下の動画は投稿用ページに出さない（`post_min_duration_sec`。公開ページのピックアップには影響しない）
  - 検索に載らないよう `noindex, nofollow` を指定し、トップページからはリンクしない。ファイル名は推測されにくいランダムな文字列にする
  - 各投稿に「この動画を除外」「このチャンネルを除外」ボタン。押すと `~/youtube-indie-songs/excluded.json` に保存され、次回の更新から公開ページ・投稿用ページのどちらにも二度と載らない（チャンネルは記録済みチャンネルからも外す）。ページ下部の除外リストから「元に戻す」もできる
    - 受け口 `exclude-xxxx.php` は fetch.php が投稿用ページと同じフォルダに自動で作る。合言葉（API キーから自動生成）が合わない要求は拒否する
  - robots.txt には書かない（書くとページの場所を公開することになり、noindex も読まれなくなるため）
  - 動画説明欄 → チャンネル説明文の順に X アカウント（x.com/〜、twitter.com/〜、「X: @〜」など）を探し、見つかれば投稿文に @ で入れる
  - 投稿文は X の 280 字（日本語 2 字換算・URL 23 字）に収まるようタイトルを自動で切り詰める

## 公開ページの構成と X ポストボタン

公開ページ（index.html）の各動画に「𝕏 でポスト」ボタンがあり、押すと投稿文入りの X 投稿画面が開く。

| 欄 | 内容 | 投稿文の 1 行目 |
|---|---|---|
| ピックアップ | 上記の自動選定 | 🎤 初期推しピックアップ（投稿用ページと同じ文面） |
| 🌱 芽吹き | 新着リストの再生数トップ 10（`mebuki_limit`） | 🌱 芽吹き｜再生数ランキング N位（＋再生数） |
| 新着リスト | すべて（再生数の少ない順） | なし（ピックアップ・芽吹きとは書かない） |

どの投稿文にも X アカウント（見つかった場合）・動画 URL・#初期推し #オリジナル曲 が入る。

## 処理の流れと API 消費量（無料枠 10,000 ユニット/日）

| 手順 | API | 消費 |
|---|---|---|
| 5 キーワード × 最大 4 ページ（50 件/ページ）を検索。条件: 動画・音楽カテゴリ・3 日以内・新しい順・地域 JP・言語 ja | search.list | 100 × 20 = 2,000 |
| 候補動画の再生数・言語・再生時間を取得 | videos.list | 50 件ごとに 1（〜20） |
| チャンネルの登録者数を取得 | channels.list | 50 件ごとに 1（〜20） |

合計 約 2,050 ユニット/日。`pages_per_keyword` を増やせば取りこぼしは減る（上限目安 9 ページ程度）。

絞り込み（fetch.php 内）:
- 登録者数 0〜300（登録者数を非公開にしているチャンネルは除外）
- 日本語: 音声言語が `ja`、またはタイトル/説明文にひらがな・カタカナ・漢字を含む
- 「MV」「music video」の検索でしかヒットしなかった動画は、説明欄にひらがなが含まれるものだけ残す（オリジナル曲系のキーワードでもヒットしていれば不要）
- タイトル・タグに「歌ってみた」「カバー」「cover」「BGM」などを含む動画は除外（英単語は単語単位で判定するため "discover" などには反応しない。除外語は `config.php` の `exclude_words` で変更可）
- タグ・ハッシュタグに AI 生成を示す語（#AI, #AI音楽, #AIMusic, #suno など）がある動画は除外（`exclude_ai_tagged`）。YouTube の「改変または合成されたコンテンツ」ラベルは API で取得できないためタグで判定する。タイトル本文の「AI作曲」などは対象外。チャンネル名に AI が入っている場合も除外。`config.php` にこの項目がなくても既定で除外する
- タイトルにランキング・TOP10・まとめ・再生回数・解説・歴代・人気曲・名曲などがある動画は除外（オリジナル曲ではないランキング・まとめ動画を除く。常に適用）
- 8分以上の動画は除外（`max_duration_sec`）
- ライブ配信中・プレミア公開待ちは除外

## さくらのレンタルサーバへの設置

1. Google Cloud Console でプロジェクトを作成し「YouTube Data API v3」を有効化、API キーを発行
2. このフォルダを公開ディレクトリ外にアップロード（例: `/home/アカウント名/youtube-indie-songs/`）
3. `config.sample.php` を `config.php` にコピーして API キーを設定（出力先は自動で `~/www/indie-songs/index.html`）
4. SSH で動作確認: `/usr/local/bin/php /home/アカウント名/youtube-indie-songs/fetch.php`
5. コントロールパネル →「スクリプト設定」→「CRON設定」で登録
   - 実行コマンド: `/usr/local/bin/php /home/アカウント名/youtube-indie-songs/fetch.php`
   - 分 `0` / 時 `7` / 日・月・曜日 `*`（さくらの cron は日本時間）
6. `https://アカウント名.sakura.ne.jp/indie-songs/` で表示を確認

## 動作確認・トラブル時

- 実行のたびに `~/youtube-indie-songs/fetch.log` に結果が追記される
  - `OK candidates=… listed=…` … 正常に更新
  - `WARN search stopped …` … 検索の途中で割り当て超過など。集められた分だけで更新
  - `ERROR …` … 更新できず、ページは前回のまま
- ログに何も追記されていない日は、cron 自体が動いていない（CRON 設定のコマンド・時刻を確認）
- search.list は**1日100回まで**（1回の更新で20回使用）。リセットは日本時間16時。手動テストを繰り返すと翌朝7時の更新で上限に達することがある

## 注意点・限界

- **検索の網羅性**: search.list は 1 クエリ最大 500 件程度までしか返さず、「MV」「music video」のような広い語は 3 日分でも件数が多い。小規模チャンネルを拾うため新しい順（order=date）で取得している。取りこぼしを減らすならページ数を増やす
- **登録者数の精度**: API の登録者数は 3 桁に丸められるが、300 人以下の範囲では実質正確
- **日本語判定**: 投稿者が言語を設定していないことが多いため文字種で判定。中国語の漢字のみのタイトルが混ざる可能性がある（気になる場合はかな必須に変更）
- **歌動画の判定**: 音楽カテゴリ＋キーワード＋除外語で絞っている。除外語をタイトル・タグに書いていない歌ってみた・カバー動画は残る可能性がある
- **規約**: YouTube API 利用規約に従い、データは毎日上書きで最新化し、ページに YouTube データ由来である旨を表示している
